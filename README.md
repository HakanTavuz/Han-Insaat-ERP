# HanSiparis — Sürüm Dağıtım Deposu

Bu depo, **HanSiparis Sipariş, Cari ve Tahsilat Yönetim Sistemi**'nin derlenmiş Windows sürümlerini barındırır.

- Kurulu uygulamalar yeni sürümü bu deponun **Releases** bölümünden otomatik olarak algılar, **SHA-256 doğrulaması** yapar ve kendini günceller.
- Her sürüm, yayınlanmadan önce GitHub Actions üzerinde derleme, açılış, veri taşıma, otomatik güncelleme ve kurulum/kaldırma testlerinden geçer.
- Burada yalnızca derlenmiş dosyalar (exe) bulunur; kaynak kod ayrı tutulmaktadır.

**İndirme:** [Son sürüm → Releases](../../releases/latest) · `HanSiparis-Kurulum.exe`
